Working Directory is the project folder where developers modify files. Staging Area is a temporary area where selected changes are prepared for commit. Local Repository is the Git database stored in the .git folder on the local machine. Remote Repository (GitHub) is the centralized repository used for collaboration and sharing code.

====
git Init
======
git init initializes a new Git repository by creating a hidden .git directory in the project folder. The .git directory stores commit history, branches, staging information, and repository configuration.

=====================

 GitHub repository URL

===============
Branches
=====================

Branch = A separate copy/workspace of code for development without affecting the main code.

main branch = Production code
dev branch = Development work
feature-login branch = Login feature work
feature-payment branch = Payment feature work

main
  |
  +---- feature-login
  |
  +---- feature-payment


Why Use Branches?

Suppose your application is already running in production.

Now you need to develop a new Login feature.

If you directly change code in main, production may break.

So create a new branch:


Create a branch ---> git branch dev

switch branch ---> git checkout master/git switch master


Craete and Switch---> git checkout -b dev / git switch -c dev


see all branches ---> git branch


merge ---> git checkout master--> git merge dev


Delete branch ---> git branch -d dev
