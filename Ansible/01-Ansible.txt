===============

Ansible Server (Control Node)
IP = 10.0.1.10

Managed Server 1

====================
Step 1: Generate Key on Ansible Server
=============================
On 10.0.1.10

ssh-keygen


Private Key : id_rsa
Public Key  : id_rsa.pub

===========================
Step 2: Copy Public Key to New Server
=================================
From Ansible Server (10.0.1.10) run:

ssh-copy-id ec2-user@10.0.1.20

Meaning :

Take id_rsa.pub from 10.0.1.10
Copy it to 10.0.1.20

What happens internally?

Your public key (id_rsa.pub) is copied to 10.0.1.20:





same :

ssh-copy-id ec2-user@10.0.1.30



Step 3: Test Login

From 10.0.1.10:

ssh ec2-user@10.0.1.20


✅ No password asked
ssh ec2-user@10.0.1.30

✅ No password asked

Step 4: Add Inventory

[webservers]
10.0.1.20
10.0.1.30

Step 5: Test AnsibleA

ansible all -m ping

 One-time Ansible commands used for quick tasks without creating a playbook.

===================================================================

=====

noraml Uptime --> It will give the ansible server uptime(when the ansible server starts)

ansible all -m shell -a uptime ----> i will give the up time for the all managed Servers.


shell: it is amodule which execute Linux commands on remote servers 

Shell module in Ansible is used to run Linux shell commands on target servers.

ansible webservers -m -b shell -a "yum install git "

m-> Module

b-> becomes a root user( root previliages)

a-> Arguments 

ansible all -m  shell -a "java -version"

=====
Yum : The yum module is used to install, remove, update, and manage packages on RHEL, CentOS, Rocky Linux, AlmaLinux, Amazon Linux servers.
===


ansible all -m shell -a "maven -version"

ansible all -m -b shell yum -a "name = maven"



ansible all -b -m yum -a "name=git state=present"

name = package name
state=present = install package
state=absent = uninstall package
state=latest = update to latest version
-b = become (sudo/root)

ansible all -b -m yum -a "name=httpd state=present"

update the Git
===========
ansible all -b -m yum -a "name=git state=latest"


Install Multiple packages :
-=============================
ansible all -b -m yum -a "name=git,httpd,wget state=present"



ansible all -b -m service -a "name=httpd state=started"

===
Copy
======

====================================================
Copy the files from Control node to Managed Nodes:
======================================================

ansible <hosts/all/ip> -m copy -a "src=<source_file> dest=<destination_path>"

========================
Example 1: Copy a file:
========================

ansible all -m copy -a "src=/home/ansible/app.conf dest=/tmp/app.conf"

====================================
Example 2: Copy with root permissions:
==========================================

ansible all -b -m copy -a "src=/home/ansible/app.conf dest=/etc/app.conf"

=======================
Example 3: Copy a directory
=========================
ansible all -m copy -a "src=/home/ansible/configs/ dest=/opt/configs/"


===============
Real -time - Example
======================

Suppose you have a file:

/home/ansible/install.sh

Copy it to all target servers:

ansible all -m copy -a "src=/home/ansible/install.sh dest=/tmp/install.sh"

Then verify:

ansible all -m shell -a "ls -l /tmp/install.sh"


copy → Control Node ➜ Managed Node
fetch → Managed Node ➜ Control Node
yum → Install package
service → Start/Stop service
shell → Run Linux commands
command → Run simple commands without shell features

host a static website using ansible

==================
website.yaml :
================

---
- hosts: webservers
  become: yes(become a ansible root user)

  tasks:

    - name: Install httpd server
      yum:
        name: httpd
        state: present

    - name: Start Apache Service
      service:
        name: httpd
        state: started
        enabled: yes

    - name: Copy Website Files
      copy:
        src: index.html
        dest: /var/www/html/index.html

...

ansible-playbook website.yaml --syntax-check

ansible-playbook website.yaml --list-hosts

ansible-playbook website.yaml


==
vars--To store the data
====
Instaed of writing httpd in 2 times for above example use Vars.




website.yaml :
================

---
- hosts: webservers
  become: yes(become a ansible root user)
  vars:
   package_name: httpd
  tasks:

    - name: Install httpd server
      yum:
        name: name: "{{package_name}}"
        state: present

    - name: Start Apache Service
      service:
        name: "{{package_name}}"
        state: started
        enabled: yes

    - name: Copy Website Files
      copy:
        src: index.html
        dest: /var/www/html/index.html
