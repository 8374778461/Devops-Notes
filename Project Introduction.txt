Project Introduction

Project Name: IES (Integrated Eligibility System)

Client: Rhode Island State Government (USA)

Domain: Healthcare & Welfare Benefits

Simple Definition

IES is a government application used to determine whether a citizen is eligible for various welfare and healthcare programs and to provide benefits accordingly.

Programs covered:

SNAP (Food Assistance)
Medicaid
Medicare
CCAP (Child Care Assistance Program)
QHP
RIW (Rhode Island Works)

I worked on the Integrated Eligibility System (IES) project for the Rhode Island State Government. The application is used to determine citizen eligibility for welfare and healthcare programs such as SNAP, Medicaid, Medicare, CCAP, and RIW. The project consists of modules like Admin, User Management, Application Registration, Data Collection, Eligibility Determination, Correspondence, Benefit Issuance, and Reports. A citizen submits an application, the system collects required information, verifies eligibility based on business rules, generates approval or rejection notices, and issues benefits for eligible citizens. The application was developed using Java, Spring Boot, REST APIs, database integration, Redis caching, AWS S3 document storage, and external SSA services.
