Users Access Application

Developer pushes code to GitHub. Jenkins builds the application, creates a Docker image, and pushes it to a registry. Terraform creates infrastructure, 
Ansible configures servers, and Kubernetes deploys and manages the Docker containers with auto-scaling and self-healing.


Users normally access the application through a DNS name or AWS Load Balancer URL. The Load Balancer forwards traffic to Kubernetes Services, which then route requests to the running Pods. Users never directly access Pod IPs because Pods are temporary and can change at any time.

GitHub     -> Stores Code
Jenkins    -> CI/CD Automation
Docker     -> Package Application
Terraform  -> Create Infrastructure
Ansible    -> Configure Infrastructure
Kubernetes -> Run & Manage Containers
AWS/Azure  -> Cloud Platform
