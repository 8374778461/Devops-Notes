Project Introduction

Project Name: IES (Integrated Eligibility System)

Client: Rhode Island State Government (USA)

Simple Definition

IES is a government application used to determine whether a citizen is eligible for various welfare and healthcare programs and to provide benefits accordingly.

Programs covered:

SNAP (Food Assistance) :Supplemental Nutrition Assistance Program (SNAP
Medicaid : Health insurance for people with low income in the United States.
Medicare: Health insurance mainly for senior citizens (65+) in the United States.
CCAP (Child Care Assistance Program)
QHP
RIW (Rhode Island Works)

I worked on the Integrated Eligibility System (IES) project for the Rhode Island State Government. The application is used to determine citizen eligibility for welfare and healthcare programs such as SNAP, Medicaid, Medicare, CCAP, and RIW. The project consists of modules like Admin, User Management, Application Registration, Data Collection, Eligibility Determination, Correspondence, Benefit Issuance, and Reports. A citizen submits an application, the system collects required information, verifies eligibility based on business rules, generates approval or rejection notices, and issues benefits for eligible citizens. The application was developed using Java, Spring Boot, REST APIs, database integration, Redis caching, AWS S3 document storage, and external SSA services.

What is Kafka?

Apache Kafka is a message broker used to transfer data/messages between applications.


"Kafka is a distributed messaging system that allows one application to send data and another application to receive data in real time."

Real-Time Example

Suppose you order food on Swiggy:

You place an order.
Order Service generates an order message.
Kafka receives the message.
Restaurant Service receives the message.
Payment Service receives the message.
Notification Service sends SMS/Email.

Without Kafka, each service must directly communicate with every other service.

With Kafka, all services communicate through Kafka.

Order Service
      |
      v
    Kafka
   /  |  \
  v   v   v
Payment Notification Restaurant
Service  Service      Service


Main Components
1. Producer

Application that sends messages to Kafka.

Example:

Order Service sends order details.
2. Topic

A category where messages are stored.

Example:

orders
payments
notifications

3. Consumer

Application that reads messages from Kafka.

Example:

Payment Service reads order messages.
4. Broker

Kafka Server itself.
